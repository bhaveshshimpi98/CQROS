---

# 1. Purpose

The Dataset Builder layer transforms validated market data into
standardized, reproducible, research-ready datasets.

Every dataset generated by CQROS must be deterministic,
fully versioned, and reproducible.

---

# 2. Responsibilities

This layer owns

- Dataset construction
- Dataset synchronization
- Symbol alignment
- Time alignment
- Resampling
- Window generation
- Gap handling
- Dataset merging
- Dataset filtering
- Dataset versioning
- Dataset publishing

---

# 3. Out of Scope

Layer 06 does not perform

- Data ingestion
- Storage
- Validation
- Feature engineering
- Target generation
- Model training
- Trading

# 31. Summary

The Dataset Builder layer transforms validated market data into
research-ready datasets that are deterministic, reproducible,
fully versioned, and optimized for quantitative research.

It serves as the bridge between infrastructure layers and the
research pipeline, ensuring that every downstream feature,
target, model, and strategy operates on consistent, high-quality
datasets.
